上手只要五步

  1. 下载并解压

    下载 MeguLit-v1.2.8-win-x64.zip，解压到任意文件夹，运行 MeguLit.exe

  2. 选完整版或精简版

    完整版约 565 MB，注音词典和语音引擎一次装好，推荐选这个；精简版约 107 MB，缺的组件以后可以在设置里补

  3. 选游戏文件夹

    选好放游戏的文件夹，MeguLit 会连 Steam 库一起扫一遍，自动找到日文原版的 EXE，同一系列的作品也会归在一起

  4. 启动游戏，用窗口模式玩

    点作品，再点「启动游戏」，阅读层会自己接上。按 Alt + T 打开菜单

  5. 零基础先学五十音

    学习 → 五十音：25 课、五十音图，再加三个假名小游戏，例句都来自你自己玩过的游戏

    试着复习一张卡

    点一下翻面，拖开换下一张。MeguLit 做出来的卡片就长这样：正面是游戏里碰到的词，背面是意思，还有你读到它时的那一幕

    键盘：Enter 翻面，→ 下一张

    訳

    汉化补丁就是译文，一句不等

    装了汉化补丁的游戏，MeguLit 会直接拿补丁里的译文对照日文原文，台词一出来译文就到了。KiriKiri、BGI、Siglus、YU-RIS、Artemis、Ren'Py 都实际测过；补丁里没翻的句子，会提前用机翻补上

    振

    注音先听游戏的

    游戏自己标了注音的地方，就照游戏的读音来；没标的，再根据词典和上下文判断。人名、当て字的念法也跟着作品走

    辞

    点一下查词，拖一段查短语

    词典是离线的，查过的词会自动进单词本。选中整句，还能让 AI 讲讲语法和语境。翻译可以接 DeepL、Google、Gemini、DeepSeek、Sakura、Ollama 等，密钥加密后只存在你电脑上

    少折腾

    换回日文原版

    MeguLit 读的是日文台词，所以游戏剧情得是日文。Steam 上的中文、英文版可以一键切回日文；手上有日文原版的话，压缩包、文件夹、光盘镜像都能直接选，MeguLit 会自动对照着替换

    • 支持 .iso、.bin / .cue 光盘镜像，只有 InstallShield 安装程序的老光盘也能直接解包
    • 替换前全部备份，一键还原
    • 打开的是中文版时，会直接告诉你怎么换回日文

    自动更新

    每次打开都会看看有没有新版本，有的话就在后台下载好、校验完，再问你要不要重启更新。只换程序文件，游戏库、学习记录和设置都不动

    不放心的话，先核对一下文件

    1. 在下载文件夹的空白处按住 Shift 点右键，选「在终端中打开」
    2. 输入 Get-FileHash .\MeguLit-v1.2.8-win-x64.zip 回车
    3. 输出的 Hash 和上面的 SHA-256 一字不差，就是官方原包。安装包只在 GitHub ilynthn/MeguLit 发布，本站镜像只做同步

    常见问题

    全屏玩的时候翻译显示不全，或者文字跑到了桌面上

    把游戏切成窗口模式就好。独占全屏时游戏会盖住所有窗口，阅读层没法稳定地显示在游戏上面。窗口拉大一点没关系

    读到的是乱码，或者根本不是日文

    剧情得是日文原文才行。如果是汉化版，先试试「工具 → 日文原版恢复」；如果只是抓错了文本，在阅读层里一键重新选就好

    下载很慢，或者打不开 GitHub

    这页的下载按钮默认走 megulit.com 自己的镜像，和 GitHub Releases 自动同步。镜像不行的话，「备用下载」里还有两个 GitHub 加速镜像，以及 GitHub 直连

    更新会不会弄丢我的数据

    不会。自动更新只替换程序文件，data、logs、cache、runtime、models 都不碰，旧的 MeguLit.exe 还会留一份 MeguLit.rollback-update.exe

    点「启动游戏」提示「无法检查游戏是否已运行」

    v1.1.0 已经修好了。旧版本在少数电脑上会这样，多半是杀毒软件拦住了进程查询，更新到新版就行

    Anki 连不上

    先把 Anki 打开，并装好 AnkiConnect（在 MeguLit 里能一键装）。另外，8765 端口被别的程序占了也会连不上

    某个游戏读不到文字

    不同引擎差别很大。请在 GitHub Issues 留下游戏名，最好附上 MeguLit 的 logs 文件夹

    要钱吗？会收集我的数据吗？

    免费，源码以 GPL-3.0 开源。学习记录和设置都存在你自己的电脑上；翻译服务的密钥加密存在本地，只会发给你选的那一家
