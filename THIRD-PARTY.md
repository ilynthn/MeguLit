# Third-party inventory (migration work in progress)

This is an inventory, not a claim that the complete project's license audit is finished.

- New project code uses the existing project's GPL-3.0-or-later declaration. See LICENSE
- Tauri, Wry, WebView2 bindings, native menu/tray/dialog libraries, Serde and transitive dependencies: exact versions in `desktop/Cargo.lock`; retain their individual package notices when producing a distribution
- Node.js: bundled runtime with its original `runtime/NODE-LICENSE.txt`
- Microsoft WebView2 loader: generic x64 dependency artifact; the Evergreen WebView2 runtime is installed separately
- `web/grammar-ruby.js` (furigana for MeguLit's own grammar example lines) is generated by `tools/build-grammar-ruby.cjs` from JMdict readings (EDRDG licence, CC BY-SA 4.0) chosen in context by the Sudachi tokenizer; 蓝宝书 grammar cards are read from the learner's own Anki at run time and never shipped.
- JMdict-derived data: imported from the user's existing dictionary data. Retain the dictionary source attribution and applicable data/translation notices before public distribution; the data is not newly authored by this rewrite
- LunaHook and its engine adaptations: source and notices retained under `preserved/source/`; the custom native/runtime bridge is now integrated with the independent reader, with live game verification still pending
- LunaHook MAGES character table (GPL-3.0): `services/original-engines/mages-charset-sghd.txt` is copied from LunaHook's MAGES engine adaptation and used to decode STEINS;GATE scripts for zero-latency translation
- MinHook 1.3 (Tsuda Kageyu, BSD 2-Clause): vendored under `native/scncapture/minhook/` with its `LICENSE.txt`, linked into `native/MeguLitScn32.dll` / `MeguLitScn64.dll` (KiriKiri Z scene capture)
- MinHook 1.3 (Tsuda Kageyu, BSD 2-Clause): also vendored under `native/runtimedump/minhook/`, linked into `MeguLitDump32.dll` / `MeguLitDump64.dll`, which ship in the hidden on-demand runtime pack `runtime/runtime-dump` (docs/runtime-dump-pack.md)
- Textractor (Artikash, GPL-3.0) / LunaHook (HIllya51, GPL-3.0): the memory text search in `native/runtimedump/RuntimeDump.cpp` (seed expansion: needles per encoding, region walk, readable-page checks) follows their SearchForText / Util::SearchMemory
- GARbro (morkt, MIT) and vgmstream (ISC-style): the voice file magic table in `native/runtimedump/modules/Voice.cpp` (Ogg Vorbis/Opus, WAV, AT9 sub-format GUID, BGI `bw  ` header, CRI HCA incl. masked header, CRI ADX `(c)CRI`, FSB5, ID3) follows their format detection; facts only, no code copied
- KrkrDump (crskycode, GPL-3.0): `native/runtimedump/modules/Krkr.cpp` ports its TVPCreateStream signatures (KRKRZ MSVC, KRKR2 BCB thunk), the GetProcAddress("V2Link") wait and the KAG SimpleCrypt decoder; KrkrExtract (xmoezzz, no licence) was read for ideas only, no code taken
- KiriKiri 2 plug-in SDK stub (`tp_stub.h` / `tp_stub.cpp`, W.Dee and contributors, KiriKiri license / GNU GPL dual license, GPL chosen): copied unmodified from https://github.com/krkrz/krkr2 into `native/krkrtext/sdk/` with its `license.txt`, linked into `native/MeguLitKrkr32.dll` (KiriKiri text positions)
- rlvm / libreallive (Peter Jolly, https://github.com/eglaysher/rlvm, MIT licence for libreallive): RealLive Seen.txt index, scenario header, XOR-masked LZ decompression and the per-title second-level XOR keys, ported to JavaScript in `services/original-engines/reallive.cjs` (archive.cc, scenario.cc, compression.cc). No rlvm code or binaries bundled.
- GARbro (morkt, https://github.com/morkt/GARbro, MIT License): archive layouts and per-game keys reimplemented in JavaScript, no GARbro code or binaries bundled. Nitro+ NPK2 keys and PAK layout (`services/original-engines/npk.cjs`, `nitro-pak.cjs`), Noesis IGA (`iga.cjs`), Musica PAZ keys and type passwords (`paz.cjs`), Bruns EENC/EENZ (`bruns.cjs`), KiriKiri cx archive filter (`cx-filter.cjs`, ported from `ArcFormats/KiriKiri/KiriKiriCx.cs` and `YuzCrypt.cs`, with the cx parameters of every title in `cx-schemes.json` taken from the `Formats.dat` of the crskycode/GARbro fork, MIT), taken from GARbro 1.5.44 sources and its `GameData/Formats.dat` E450 game voices: Musica PAZ voice.dat keys and type password (Formats.dat PazScheme), CatSystem2 KIF entry-name cipher and V_CODE2/KEY_CODE passphrase (ArcINT.cs), FVP .bin and IGA layouts. Yuzusoft xp3 name tables (sen:/yuz:/cbg:/dls:) with the NanaDecryptor / YuzDecryptor name-list ciphers and the schemes' YuzKeys (YuzCrypt.cs).
- Hxv4 (cxdec v2) index / stream function byte patterns: the two code patterns in `native/scncapture/ScnCapture.cpp` are the ones published by open-source Hxv4 extractors (e.g. YeLikesss/KrkrExtractForCxdecV2); only the byte patterns are used, no code is copied, and the functions are called inside the user's own game process
