# 合成回放夹具

新增基线由主线 `e93c03e1` 的学习器、字体匹配器、独立绘制模块和放置链路直接生成。原生夹具使用 `MEGULIT_GPU_REPLAY 1`，内容是合成字形、几何和时序。以 `replay.exe --check <夹具目录>` 检查全集，尾部可加单个夹具名。

| 夹具 | 来源 | 冻结行为 |
| --- | --- | --- |
| `mages` | 合成 | 旧行留在页上时，第二句等自己的新行再上报字位。两行上方的注音一起隐藏，远处同尺寸图标保留。 |
| `nitro-targets` | 合成 | 正文和阴影各用一个同尺寸渲染目标，两张已学习图集都隐藏。源句带空隙重复时只计一次。新图集整页重画的隐藏窗口到期后，原画恢复。 |
| `nitro-page` | 合成 | 运行时字表换页纹理后，整页重画仍按原位置隐藏两行，留出未认领的菜单字形。 |
| `littlecheese` | 合成 | 首句回调前已隐藏保留位图的正文。`Rows::Claim` 按绘制顺序分别认领内容相同的两行，切回只读后下一行保留。 |
| `sact2` | 合成 | 以选流后的绘制许可驱动 `Sact2::DrawCount`。手动选中正文时只跳过正文保留名牌，未授权和履历保留。自动战斗阶段隐藏合法气泡，保留菜单和错格气泡。 |
| `nexas` | 合成 | 同字体选项紧跟正文，后续字形保留并上报选项文字。整句重新光栅化时正文仍隐藏。 |
| `softpal` | 合成 | GPU 发现清醒的文本窗且未武装。配套放置回放给同一个 `ToMe_PAGE` 输入三种时刻的写回状态，对照放置消息与阅读层实测可见性。 |
| `aoitori-cmvs-cold-start` | 合成，取实机几何和顺序 | 第一句钩子只有 19 字，游戏画了 23 格。遮住全部 23 格，19 个上报框覆盖整行。两句各发一次隐藏坐标。 |
| `aoitori-cmvs-user-corner` | 合成，取实机几何 | 框角与 13 个正文格凑满 15 个位置时等正文画齐。只发一次 15 字的隐藏坐标。 |
| `aoitori-cmvs-user-mixed` | 合成，取实机几何 | 新字、上句残余和框块共计 23 个位置。逐报检查，整句坐标来自同一帧的 23 个正文字格。 |
| `aoitori-cmvs-user-two-rows` | 合成，取实机几何 | 跳过图集第零格与三个绘制空格。连报完整的 36、32、26 字双行。后一报等候复用格更新，略过刚好凑够 26 格的旧行残留。 |

**现状，非期望。** `mages` 的 `MASK 2.0` 只有旧行，但仍收到 `hit seq=2`。第二句字位在新行画出后才上报。`nexas` 的 `MASK 0.1 0` 仍隐藏同字体选项突发的首个复用字形。两个快照都供重构前后对照，修复相应行为时应更新它们。

Littlecheese、SACT2、NeXAS 的内置夹具会在 v1 绘制批次中记录合成字形及测量格。SACT2 用合成事件传入精灵原点，桥侧手动选流另外由 `HookBridge.exe --self-test` 验证。`softpal-placement.expected.json` 消费原生回放的页消息，用 `node --test validation/softpal-placement-replay.test.cjs` 验证。在有 Edge 的环境里会再核对原文和译文的可见性。
